# Demos

Working demo pages. Each folder is one demo, served at
`https://hamzachaudhary94.github.io/demos/<folder>/`

## Publish

    ./publish.sh <folder>

## Rules

**This repo is PUBLIC.** Nothing private goes in it, ever. No client lists, no
personal files, no credentials, no anything from the Second Brain.

**A demo is never a copy of somebody's site.** No logos, no scraped photos, no
branding that could be mistaken for theirs. Every page says on its face that it
is a demo and not the business's real site.

**No demo collects real customer data.** Forms are for show and post nowhere.
